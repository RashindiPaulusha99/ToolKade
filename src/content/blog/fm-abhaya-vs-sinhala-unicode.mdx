If you have ever pasted Sinhala text into a design and watched it turn into a string of English letters like `,xld`, you have met the difference between **FM Abhaya and Sinhala Unicode**. This guide explains what each one is, why they do not mix, and how to move text between them safely. ## What is FM Abhaya?

**FM Abhaya** is one of the best-known Sinhala fonts from the era before Sinhala was widely supported on computers. Like other "legacy" fonts, it uses a simple trick: it takes ordinary keyboard characters and draws Sinhala shapes in their place.

So the letter `l` is drawn as **ක**, `k` is drawn as **න**, and `w` is drawn as **අ**. On screen it looks like Sinhala, but underneath, the computer only stores Latin letters and symbols. Change the font, or open the file on a computer without FM Abhaya, and the Sinhala disappears.

## What is Sinhala Unicode?

**Unicode** is the international standard that gives every character in every writing system its own code. In Sinhala Unicode, **ක** is stored as the actual Sinhala letter ka, not as a Latin `l`.

That means Unicode Sinhala text:

- displays correctly in any Sinhala Unicode font (Iskoola Pota, Noto Sans Sinhala and others),
- works on phones, websites, social media and email,
- can be searched, sorted, spell-checked and read by screen readers and search engines.

## Why conversion is harder than swapping letters

You cannot convert FM Abhaya to Unicode by replacing one letter at a time, because the two systems store syllables in a **different order and shape**:

- **Kombuva (ෙ) comes first in FM Abhaya.** Unicode stores කෙ as "ක then ෙ", but in FM Abhaya you type the kombuva `f` before the letter: `fl`.
- **Conjuncts have their own keys.** Yansaya (්‍ය), rakaransaya (්‍ර) and repaya are separate marks in FM Abhaya (`H`, `%` and `¾`), while Unicode builds them from the letter, the al-lakuna (්) and an invisible joiner.
- **Some combinations are single glyphs.** FM Abhaya has dedicated glyphs for shapes such as **වි**, **දු** and **ළු**, because the plain vowel sign would sit in the wrong place.
- **Punctuation moves.** FM Abhaya uses keys like the comma and full stop for Sinhala letters, so real punctuation has to be typed with other keys.

A good converter works syllable by syllable and rebuilds each one in the other system.

## Common mistakes and tips

**Changing the font instead of converting.** Selecting FM Abhaya on Unicode text (or a Unicode font on FM text) does not convert anything. You need to convert the text first, then apply the font.

**Mixing English into FM Abhaya text.** FM Abhaya uses the English letter keys for Sinhala shapes, so English words inside FM text turn into Sinhala gibberish. Keep English in a separate text box or font.

**Copying from PDFs.** Text copied from a PDF made with a legacy font often comes out in the wrong order or with missing glyphs. Check the converted text carefully before you use it.

**Publishing FM text online.** If you put FM Abhaya text on a website or social media, most readers will see random Latin letters, and search engines will not understand it. Convert it to Unicode first.

**Keeping a Unicode master copy.** If you work in FM Abhaya for print, keep the original Unicode text too. It is much easier to edit, search and reuse.

## Conclusion

FM Abhaya and Sinhala Unicode can look identical on screen, but they store text in completely different ways. FM Abhaya is a font trick on top of Latin characters, while Unicode stores real Sinhala characters that work everywhere. Use Unicode for anything digital, and convert to FM Abhaya only when a design or print workflow needs it.
